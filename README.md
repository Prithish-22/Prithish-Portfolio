# Prithish Raj T — AI/ML & Data Science Portfolio

Interactive, premium 3D portfolio showcasing work at the intersection of Artificial Intelligence, Machine Learning, and Data Science.

## 🚀 Features

- **3D Neural Network Lattice:** Interactive Three.js/R3F WebGL visualization in the Hero section.
- **Interactive Linear Regression Visualizer:** 3D least-squares fit simulator with dynamic residuals.
- **Curated Projects Showcase:** Featuring **BFX Vesper** (1st place at VIT Vellore Hackathon).
- **Responsive & Mobile-Optimized:** Seamless layout across all device widths.
- **Fast & Modern Stack:** Powered by React 19, TypeScript, Tailwind CSS, and Vite.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS
- **3D & Graphics:** Three.js, `@react-three/fiber`
- **Animations:** Framer Motion

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
